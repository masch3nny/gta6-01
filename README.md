**Solmar Bay** — an original open-world crime game in the browser. Explore a sun-soaked coastal city on foot and by car, steal cars, outrun the Bayfront police as your wanted level climbs, and run five story jobs for fixer Vera Solano. Traffic, pedestrians, combat, a HUD with a live minimap, missions, and a save — all in plain static files with Three.js vendored offline. No Rockstar assets, no borrowed names: the city, the characters and the story are our own.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. WASD to move/drive, mouse to look, E to enter a car, click to shoot, F to punch, M for jobs, Esc to pause.
